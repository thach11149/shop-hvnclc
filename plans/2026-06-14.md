### Task 2 — ProductDetailPage tích hợp thật (buyer-web)

Trang hiện tại chỉ có thông tin sản phẩm cơ bản. Thêm:

**Q&A section** (dùng component `ProductQnASection` đã có):
- Load danh sách câu hỏi từ `GET /products/:id/qna`
- Form đặt câu hỏi (chỉ hiện khi đã đăng nhập)
- Hiển thị câu trả lời của seller

**Rating breakdown:**
- Chart cột 5 mức (1-5 sao) với % từng mức
- Gọi `GET /products/:id/reviews?summary=true`

**Recommendations widget:**
- "Sản phẩm tương tự" — gọi `GET /ai/recommendations/product?productId=:id`
- Hiển thị dạng horizontal scroll 4-6 sản phẩm

### Task 3 — CategoryManagementPage nâng cấp (admin-console)

Trang `/categories` hiện chỉ list phẳng. Làm thật:

- **Tree view** hiển thị cây category theo level (indent + icon mở/đóng)
- **Inline actions:** đổi tên (click để edit), bật/tắt, xóa (confirm dialog)
- **Thêm category:** form modal — tên, parent, slug, upload ảnh
- **Drag để reorder** trong cùng level (dùng `@dnd-kit/sortable` hoặc `react-beautiful-dnd`)
- API cần: `GET /categories/tree`, `POST /categories`, `PATCH /categories/:id`, `DELETE /categories/:id`
- Backend: thêm endpoint `GET /categories/tree` trả về nested structure nếu chưa có

---

### Task 4 — SellerDashboard nâng cấp với real-time (seller-center)

DashboardPage hiện chỉ hiển thị số tĩnh. Làm thật:

**Metrics thật từ API:**
- Doanh thu hôm nay / tuần / tháng: `GET /seller/analytics/revenue?period=today|week|month`
- Đơn hàng theo trạng thái (pending/processing/shipped): `GET /seller/analytics/orders`
- Top 5 sản phẩm bán chạy: `GET /seller/analytics/top-products`
- Tỷ lệ hủy đơn: từ order analytics

**Chart doanh thu 30 ngày** dùng `recharts`:
- LineChart với tooltip, responsive container
- So sánh với 30 ngày trước (đường thứ 2)

**Real-time đơn mới:**
- Kết nối Socket.io, lắng nghe event `new-order`
- Toast notification + cập nhật số đếm pending orders ngay lập tức
- Backend cần emit event khi order mới được tạo (trong `order.service.ts`)

### Task 5 — OrdersPage seller — bulk actions thật

OrdersPage hiện chỉ list đơn. Thêm:

**Filter nâng cao:**
- Lọc theo ngày (date range picker)
- Lọc theo trạng thái (multi-select)
- Lọc theo kho hàng
- Search theo mã đơn / tên người mua

**Bulk actions:**
- Checkbox chọn nhiều đơn
- "Cập nhật tracking" hàng loạt → modal nhập tracking code
- "In phiếu giao hàng" → generate PDF hoặc print-friendly page cho các đơn đã chọn
- "Xác nhận đã giao" hàng loạt → PATCH nhiều đơn cùng lúc

**API backend cần thêm:**
- `PATCH /seller/orders/bulk` — bulk update status/tracking
- `GET /seller/orders/:id/shipping-label` — trả về data để in phiếu
